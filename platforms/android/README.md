# Android TV / Airtel Smart Box

The Android edition (TV Home) lives in **[G41US/tv-vibehack](https://github.com/G41US/tv-vibehack)** and is released from there (Downloader code 2960939). It is not built, copied or changed by this repository.

Keep it that way:
- Its updater follows tv-vibehack's *latest* release, so never publish a TV-port package as a release of tv-vibehack.
- This repository's releases use `tizen-v*`, `webos-v*` and `vidaa-v*` tags and are never marked latest.
- Shared visual assets (Outfit font, the five wallpapers) were copied from tv-vibehack; changes to them here do not flow back.
