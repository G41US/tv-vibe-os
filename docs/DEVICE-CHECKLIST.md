# Device compatibility checklist

For each test device, capture:
- Manufacturer and full model code
- Model year and sales region
- VIDAA version and firmware build
- Built-in browser name/version, if available
- Remote directional/OK/back behavior
- Whether official developer mode is available
- Approved installation/deployment route
- Screen resolution, performance and network behavior
- Test date and pass/fail notes

Do not publish personal account details, serial numbers or network credentials.
